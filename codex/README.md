# Codex Handoffs

이 디렉터리는 AI Compass 구현 작업을 Codex에 넘기기 위한 승인된 구현 명세를 보관합니다.

## Rule

Codex에는 단순히 "PWA를 만들어라"라고 요청하지 않습니다. 구현 전에 다음을 명세합니다.

- 데이터 스키마
- 화면 및 내비게이션 구조
- Analysis Canvas progressive disclosure
- Autonomy 판정 규칙
- Trigger 규칙
- Reversibility 규칙
- Decision 상태
- localStorage 구조
- 검증 및 acceptance criteria
