# AI Compass PWA

AI Compass의 Analysis Canvas를 인터랙티브 도구로 구현하는 영역입니다.

## Planned versions

- `v1/` — 초기 용어·개념 학습 MVP 보존
- `v2/` — Analysis Canvas 기반 구현

## v2 design baseline

1. Purpose & Stakes
2. Model
3. Context
4. Action / Tools
5. Autonomy
   - Level L0~L4
   - Trigger
6. Control
   - Permission
   - Approval
   - Observability
   - Stop
   - Recovery
7. Reversibility
8. Decision
   - YES
   - CONDITIONAL
   - NO
   - UNKNOWN

같은 분석 객체를 60초, 5분, 상세 검토의 세 해상도로 보여주는 Progressive Disclosure 구조를 사용합니다.
