# AI Compass Autonomy Lab v0.1

## Learning goal

Learner can classify **Autonomy Level** and **Trigger** separately and explain the reason.

## Rule card

### Level
- L0 응답형
- L1 도구보조형
- L2 감독수행형
- L3 목표위임형
- L4 지속위임형

### Trigger
- Manual
- Scheduled
- Event-triggered
- Condition-triggered

### Two reminders

> 자율성은 “스스로 시작하는가”가 아니라 “스스로 무엇을 할지 고르는가”로 정한다.

> L3는 끝나면 사라지고, L4는 끝나도 남는다.

## Activity A — Quick Classification

각 사례에 `Level / Trigger`를 적고 이유를 한 문장으로 설명하십시오.

1. 질문에 답변만 하는 AI
2. 검색 도구를 사용해 보고서를 작성하고 끝나는 AI
3. 여러 자료를 조사하고 메일 전송 전에 사람 승인을 받는 AI
4. 목표를 받아 여러 파일을 조사·수정하고 완료 후 보고하는 AI
5. 새 메일을 계속 관찰하며 업무 목표에 따라 처리하는 AI
6. 매일 오전 9시에 고정된 문장을 자동 전송하는 시스템

### Answer guide
1. L0 / Manual
2. L1 / Manual
3. L2 / Manual
4. L3 / Manual
5. L4 / Event-triggered
6. L0 / Scheduled

## Activity B — Find the Wrong Reason

### 주장 1
“자동으로 시작하니까 L4다.”

Correction:
Trigger와 Level을 혼동했다.

### 주장 2
“승인 단계가 없으니까 L3다.”

Correction:
L3에는 목표를 받아 여러 행동을 스스로 선택하고 결과를 보고 다시 판단하는 반복 구조가 필요하다.

### 주장 3
“사람이 승인하니까 무조건 L2다.”

Correction:
작업이 끝난 뒤에도 목표·권한·상태가 남아 다시 판단하는 시스템이라면 L4일 수 있다.

## Activity C — Change One Thing

기본 시스템:
“사람이 시작하면 과제 파일 하나를 읽고 요약해 화면에 보여준다.”

한 요소씩 바꾸고 판정이 달라지는지 토론합니다.

A. 검색 도구를 추가한다.
B. 요약을 지정된 문서에 저장한다.
C. 여러 자료를 스스로 찾고 충분한지 판단해 반복한다.
D. 최종 이메일 전송 전에 반드시 승인받는다.
E. 작업이 끝난 뒤에도 새 자료를 계속 관찰한다.

Goal:
자율성 Level은 기능 하나의 이름이 아니라 **시스템의 반복·승인·지속성 구조**를 보고 판정한다.
