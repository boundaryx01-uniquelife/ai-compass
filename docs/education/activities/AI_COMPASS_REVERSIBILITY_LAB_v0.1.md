# AI Compass Reversibility Lab v0.1

## Learning goal

Learner can judge the reversibility of an action from **context and impact**, not the action label alone.

## Core question

> 이걸 되돌리려면 다른 사람에게 부탁해야 하는가?

## Traffic Light

- GREEN: 외부 상태 변화가 없거나 되돌릴 것이 거의 없음
- YELLOW: 외부 상태는 바뀌지만 사용자가 혼자 되돌릴 수 있음
- RED: 다른 사람의 협력이 필요하거나 이미 발생한 영향을 회수하기 어려움

## Activity A — Same Verb, Different Risk

다음 쌍을 비교하고 색을 정하십시오.

### 삭제
A. 내 컴퓨터의 임시 파일 삭제
B. 교사 20명이 함께 쓰는 공유 폴더 파일 삭제

### 수정
A. 내 비공개 초안 수정
B. 학생 공식 기록 수정

### 전송
A. 이메일 초안 작성
B. 학생·학부모에게 이메일 발송

### 게시
A. 비공개 메모 작성
B. 학교 공식 홈페이지에 게시

## Activity B — Put the Approval Gate

다음 흐름에서 사람이 반드시 확인해야 할 지점을 고르십시오.

```text
자료 읽기
→ 요약 생성
→ 문장 다듬기
→ 수신자 확인
→ 이메일 전송
```

Discussion:
- 모든 단계에서 승인받는 것이 최선인가?
- RED 행동 직전에 좁은 승인 지점을 두는 편이 더 실질적일 수 있는 이유는 무엇인가?

## Activity C — Change the Context

기본 행동: `파일 이름 변경`

1. 개인 연습 폴더
2. 개인 업무 폴더
3. 팀 공유 폴더
4. 학교 전체 공유 폴더
5. 외부에 공유된 링크가 연결된 폴더

질문:
- 같은 행동 이름인데 왜 색이 달라질 수 있는가?
- 영향받는 사람과 복구 방법은 어떻게 달라지는가?

## Instructor note

정답 색 자체보다 **판정 근거**가 중요합니다. 실제 상황에서는 백업·권한·공유 범위 등에 따라 같은 사례도 판정이 달라질 수 있습니다.
